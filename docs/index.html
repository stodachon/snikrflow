SnikrFlow
GitHub PyPI Docs

Stop guessing where to start reversing a binary.

Native binary security triage and reachability platform, built on angr + Claripy. Point it at an ELF or an Android APK — it tells you which functions actually deserve your attention, before you spend two hours finding out yourself.

$ pip install snikrflow
snikrflow audit libfoo.so
SnikrFlow Security Audit ════════════════════════════ Binary Architecture: arm64 Type: Shared Object Functions 159 discovered 3 JNI candidates Security-sensitive operations 3 identified Interesting paths 1 statically reachable 1 selected for data-flow analysis Findings [MEDIUM] JNI -> memory Source: Java_sg_vantagepoint_uncrackable3_MainActivity_init @ 0x403310 Sink: strncpy @ 0x400d70 (memory) Status: statically_reachable Confidence: inconclusive Risk levels are a prioritization aid, not confirmed vulnerabilities.

The pipeline

Every command feeds the next. Run them individually while you explore, or let audit orchestrate the whole thing.

  1. infoELF metadata — architecture, entry point, sections, symbols
  2. functionsFunction discovery via angr's CFGFast, cross-referenced with the symbol table
  3. jniStatically-exported JNI entry points, with best-effort Java class/method demangling
  4. sinksSecurity-sensitive calls — memory, process execution, filesystem, networking, dynamic loading
  5. cfg / callers / calleesControl-flow graph summary and call-graph queries on any address
  6. reachStatic call-graph reachability between a source and a sink
  7. solveSymbolic execution — a concrete candidate input that walks a given path
  8. dataflowDoes the source's data actually reach the sink's argument, not just control flow
  9. auditOrchestrates everything above into ranked, risk-scored findings — accepts .so or .apk directly

Read results carefully

SnikrFlow is deliberate about what different results mean. These are never used interchangeably.

TermMeaning
statically_reachableA direct call-graph path exists. Doesn't see indirect calls (function pointers, vtables).
SAT (solve)A concrete candidate input exists that walks this exact path. Not a confirmed exploit.
POSSIBLE (dataflow)Symbolic input appears to reach the sink's argument. Heuristic, not sound taint analysis.
Risk level (audit)A prioritization signal. Never a confirmed vulnerability.
